# IdeaFlow — Database Schema

## Strategy
- **DEV**: SQLite at `./data/ideaflow.db`
- **PROD**: MongoDB Atlas (same field names, different driver)
- Switch is controlled by `NODE_ENV` in `backend/src/db/connection.ts`

---

## Collection / Table: `ideas`

| Field | Type | Required | Description |
|---|---|---|---|
| `id` | UUID/ObjectId | auto | Primary key |
| `userId` | string | yes | Owner (JWT sub) |
| `rawTranscript` | string | yes | Original voice input |
| `title` | string | yes | Auto-generated by Claude (short) |
| `score` | number (1-10) | yes | Claude's overall rating |
| `marketFit` | string | yes | Claude's market analysis |
| `feasibility` | string | yes | Claude's feasibility notes |
| `revenueModel` | string | no | Suggested monetization |
| `nextStep` | string | yes | Concrete first action |
| `tags` | string[] | yes | Auto-tags (e.g. "SaaS", "B2B", "AI") |
| `status` | enum | yes | `raw`, `active`, `archived`, `shipped` |
| `isPinned` | boolean | no | User-pinned to top 3 |
| `rank` | number | no | Current dashboard rank (1 = top) |
| `dependencies` | string[] | no | IDs of ideas this depends on |
| `createdAt` | datetime | auto | Capture timestamp |
| `updatedAt` | datetime | auto | Last modified |

### Status Flow:
```
raw → active → shipped
          ↓
       archived
```

## SQLite Init Script
Located at `scripts/init-sqlite.sql`:
```sql
CREATE TABLE IF NOT EXISTS users (
  id TEXT PRIMARY KEY DEFAULT (lower(hex(randomblob(16)))),
  email TEXT UNIQUE NOT NULL,
  name TEXT NOT NULL,
  password_hash TEXT NOT NULL,
  language TEXT DEFAULT 'de',
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE IF NOT EXISTS ideas (
  id TEXT PRIMARY KEY DEFAULT (lower(hex(randomblob(16)))),
  user_id TEXT NOT NULL REFERENCES users(id),
  raw_transcript TEXT NOT NULL,
  title TEXT NOT NULL,
  score INTEGER CHECK(score BETWEEN 1 AND 10),
  market_fit TEXT,
  feasibility TEXT,
  revenue_model TEXT,
  next_step TEXT,
  tags TEXT DEFAULT '[]',       -- JSON array stored as string
  status TEXT DEFAULT 'raw',
  is_pinned INTEGER DEFAULT 0,
  rank INTEGER,
  dependencies TEXT DEFAULT '[]', -- JSON array of idea IDs
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  updated_at DATETIME DEFAULT CURRENT_TIMESTAMP
);
```

## MongoDB Schema (Mongoose)
Located at `backend/src/models/Idea.ts`:
```typescript
const IdeaSchema = new Schema({
  userId: { type: String, required: true, index: true },
  rawTranscript: { type: String, required: true },
  title: { type: String, required: true },
  score: { type: Number, min: 1, max: 10, required: true },
  marketFit: String,
  feasibility: String,
  revenueModel: String,
  nextStep: String,
  tags: [String],
  status: { type: String, enum: ['raw','active','archived','shipped'], default: 'raw' },
  isPinned: { type: Boolean, default: false },
  rank: Number,
  dependencies: [String],
}, { timestamps: true });
```
